# 요청사항
- `view.php`, `script.js` 파일을 생성해줘.
# 세부 요청사항
## 클래스 접두어
- .ukpj__content_
### view.php 파일 생성 규칙
- 자바스크립트(`script.js`)에서 실제로 선택하거나 제어(이벤트 바인딩, 값 조회 등)해야 하는 요소에만 `## 클래스 접두어`가 접두어인 자바스크립트 전용 클래스를 추가한다.
- 스크립트에서 제어하지 않는 단순 레이아웃 컨테이너, 타이틀, 레이블, 텍스트 등에는 **절대** 클래스를 추가하지 않는다.
- 기존 html, php 구조를 유지한다.
- `## 클래스 접두어` 값이 접두어가 아닌 기존 클래스는 절대로 변경 및 삭제 불가능하다.
### script.js 파일 생성 규칙
- 업로드한 `upload_ukp_js.md` 파일에 나와있는 함수를 최대한 사용하여 작성해줘.
- `sample.js` 파일이 업로드된 경우 기존 내용에 내가 요청한 사항을 추가해줘.
- 자바스크립트 코드는 `ukp.ready(function() {});` 함수 안에 작성된다.
- post 요청은 모두 ajax로 하며 ajax 요청시 json 값을 받게된다.
- 코드를 작성하기 전 최상단에 아래 코드를 추가하며 `sample.js` 파일이 업로드된 경우 아래 코드가 없는경우에만 추가한다.
```js
/// <reference path="../../asset/js/ukp.js" />
const ukp = new Ukp();
```
