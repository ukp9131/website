# 규칙
- `# 요청사항 > ## 함수 형태 및 주석` 탭에 작성된 내용을 보고 어떤 기능을 할 것 같은지 사용예시를 보여주면서 설명해줘.
- 함수 주석 내용중에 이해가 안되거나 모호한 부분이 있으면 알려줘.
- 함수 주석 내용, 예시에 오타가 있거나 함수 파라미터, 반환값 데이터타입이 잘못되어 있는부분 알려줘.
- `require` 부분은 프로젝트 내부에서 쓰는 자체규칙이므로 파악하지 않아도 돼.
